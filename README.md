# Dulni (دلني)

## Introduction

Dulni is an AI-powered assistive navigation application designed to help visually impaired individuals navigate outdoor environments more safely and independently. The application aims to combine GPS-based navigation, Arabic voice guidance, and real-time obstacle awareness in an accessible mobile experience.

The goal of Dulni is to improve outdoor mobility and independence for visually impaired users through an accessible, voice-first navigation experience.

## Technologies Used

- **Programming Language:** Dart
- **Framework:** Flutter
- **Development Environment:** Visual Studio Code and Android Studio
- **Backend Services:** Firebase
- **Database:** Cloud Firestore
- **Authentication:** Firebase Authentication
- **Map and Location Services:** Google Maps Platform
- **Version Control:** GitHub

## Getting Started

### Prerequisites

Before running the application, ensure that the following tools are installed and configured:

- **Visual Studio Code** with the Flutter and Dart extensions.
- **Android Studio** with an Android emulator configured, or a compatible physical Android device.
- **GitHub Desktop** to clone the repository.
- **Flutter SDK** installed and added to the system PATH.

### Installation and Setup

1. **Clone the repository** using GitHub Desktop by selecting *File → Clone Repository* and choosing the Dulni repository '2026-GP1-33-Dulni'.

2. **Open the project** in Visual Studio Code by selecting *Open in Visual Studio Code* in the repository page.

3. **Navigate to the Flutter application directory** by opening the VS Code terminal and running:

   ```bash
   cd "Flutter App Files"
   ```

   Make sure the terminal is initially opened at the repository root directory.

4. **Install the project dependencies** by running:

   ```bash
   flutter pub get
   ```

5. **Start an Android emulator** from Android Studio or connect a compatible Android device with USB debugging enabled.

6. **Run the application** by executing:

   ```bash
   flutter run
   ```
